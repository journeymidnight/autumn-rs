### F-FSSPEC-1 — `autumn://` fsspec filesystem (datasets / checkpoints)
- **Trigger**: "all-in-one AI storage" — implement fsspec so Python data tooling (HuggingFace `datasets`, pandas, pyarrow) loads directly from autumn. Pure client adapter on the existing `autumn` PyO3 KV SDK; no new server wire, no data-plane bypass ([[feedback_no_parallel_data_plane]], [[feedback_client_side_complexity_first]]). Complements `autumn-fuse` (native mount) as the programmatic file surface.
- **Scope**: `python/autumn_fsspec/` — `AutumnFileSystem(AbstractFileSystem)` (protocol `autumn`, registered via import + `[fsspec.specs]` entry point). On-KV layout (`_layout.py`): reserved **`fs/` namespace** (ASCII prefix like kvcache `kvc/` / memory `doc/` — deliberately NOT autumn-fuse's `0x01`/`0x02` inode/dirent bytes, so a fuse mount + fsspec safely share one cluster). Manifest key `fs/m/+path` → tiny JSON `{t,s,cs,n,m}`; data chunks `fs/d/+path+\x00+u64(idx)` → **8 MiB** each (matches `autumn-fuse` MAX_EXTENT, ZC-eligible ≥64 KiB, under the 64 MiB inline-put cap → files of any size despite the SDK exposing only inline puts). Implicit s3fs-style dirs + explicit empty-dir markers. Reads: multi-chunk `batch_get_into` into exactly-sized buffers. **Listing: autumn `range` is keys-only (values always empty — rpc_handlers.rs `range_scan_sst_merge`), so `ls` fetches child manifests via a pipelined multi-`get`.** Model helpers (`models.py`): `upload`/`materialize` (to-local for `vllm serve`)/`load_safetensors` (bytes escape hatch). Prototype streaming loader (`vllm_loader.py`): safetensors header parse + ranged fetch (offline-tested; GPU/vLLM wiring unverified). Docs: `docs/model_loading.md` (ranked vLLM/SGLang recipes), package README, `docs/ops.md` verify section, README surface.
- **Acceptance**: offline (in-memory FakeKV mirroring the keys-only `range` contract) — full FS surface across size boundaries (0 B→multi-chunk), ls/info/find/rm, root-bucket isolation, **HuggingFace `datasets` save_to_disk/load_from_disk + load_dataset('json', data_files=…) round-trips**, safetensors header planner. ### F-FS-UNIFY — one filesystem for fuse + fsspec (shared inode layout + lease)
- **Trigger** (2026-07-03, user architectural directive): as filesystem surfaces, `autumn-fuse` (POSIX mount) and `autumn_fsspec` (Python) "should be one system, e.g. both have lease" — see the same files on the same inode layout, fenced by the same per-inode lease, not two coexisting namespaces (the F-FSSPEC-1 `fs/` namespace is deliberately separate → different files, no cross-fencing). Design-first per user (chose "design doc first" over building immediately).
- **Scope**: `docs/fs_unify_design.md` — full design. One **shared Rust FS core** (decouple `crates/fuse`'s `meta`/`dir`/`extent`/`read`/`write` from the `fuser` feature; return plain `InodeMeta`, move `→FileAttr` into `dispatch.rs`), consumed by BOTH the `autumn-fuse` binary and a new PyO3 `autumn.Fs` binding; `autumn_fsspec` rewritten as a thin facade over the shared inode layout (path↔inode, real dirents, extent read/write) with `autumn_client::lease` acquire/heartbeat/release on open/close. Prerequisite hardening: the inode allocator (`meta.rs:alloc_inode`) is a non-CAS RMW on the `next_inode` counter → duplicate inodes under concurrent allocators; fix to crash-safe multi-writer (manager `AllocInodes` RPC or SDK CAS). Phased M0(allocator)→M1(decouple)→M2(PyO3 Fs)→M3(fsspec facade, retire `fs/` layout)→M4(lease+fencing+cross-surface tests). Key enablers already exist: lease is a reusable lib (`autumn_client::lease`), namespace core is ~pure over `ClusterClient`+`key`/`schema` (thin fuser coupling only at the return boundary). Open questions for user: Q1 write-only-lease vs always-lease; Q2 allocator manager-RPC vs SDK-CAS; Q5 POSIX-surface breadth.
- **Acceptance**: (design phase — no code) design doc reviewed + approved; then per-milestone: M0 N-way concurrent alloc → unique inodes + fuse suite green; M1 `crates/fuse` builds `--no-default-features --features core` (no fuser) with the fuse binary unchanged; M2 headless create/readdir/read/write/rename via `autumn.Fs`; M3 fsspec + datasets suites green on the shared layout; M4 fencing/coherence + write-via-mount/read-via-fsspec byte-identical.
