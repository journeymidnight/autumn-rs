Use with Claude via MCP

The same binary is an MCP server over stdio (--mcp) — give Claude your agent memory as tools. Run from the autumn-rs repo root. In Claude Code:

$ claude mcp add memory -- cargo run -q -p memory-browser -- 127.0.0.1:9001 --mcp

Tools: remember · search · get_memory · put_fact · get_fact · list_facts · append_event · recent_events · link · neighbors · trace.
