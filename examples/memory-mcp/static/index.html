Use with Claude via MCP

Give any MCP client this memory as tools — code search + call graph, and document ingest/retrieval (search_docs, ingest_documents). The same binary speaks MCP over stdio with --mcp (no extra process, no Python — it queries this already-indexed agent). Run from the autumn-rs repo root. In Claude Code:

$ claude mcp add autumn-memory -- cargo run -q -p memory-mcp -- 127.0.0.1:9001 --mcp

Tools exposed: search_code · get_symbol · find_callers · find_callees · trace_call_path. For Claude Desktop, put the same command/args under mcpServers in claude_desktop_config.json.
