Stage 1 (this commit) — concrete changes:

  1. `background.rs` GC trigger (Task #1, fully unblocks empty-extent
     reclamation):
       - candidate set = all `sealed_extents` (not just `discards.keys()`).
       - empty (sealed_length=0) non-tail extents → push to holes, no
         rewrite. `run_gc(eid, 0)` already skips the read loop and
         proceeds to `flush_gc_batch` (no-op) + `punch_holes`.

  2. `background.rs` F199 cooldown classification (Task #2):
       - `gc_failure_cooldown: HashMap<u64, (Instant, Duration)>` so
         each entry carries its own window.
       - New pure helper `classify_gc_failure_cooldown(e, soft, hard)`:
         30 s window for anyhow chains containing `"precondition failed"`
         or `"eversion mismatch"`; 300 s otherwise.
       - 4 unit tests in `f201_classify_cooldown_tests` cover the
         sentinel substring shapes (top of chain, deep in chain,
         unrecognised → hard).

  3. `GcTask` multi-tier params + wire change (Task #3):
       - `GcTask::Auto(GcAutoParams { ratio, max_size, stream_debt,
         empty_only })` in `partition-server/src/lib.rs`.
       - `background_gc_loop` Auto arm consumes the params:
           - `empty_only` short-circuits to empty-extent-only picks.
           - `stream_debt` halves the per-extent ratio when total
             reclaimable bytes exceed the threshold.
           - `max_size` caps the per-extent `sealed_length`.
       - `MaintenanceReq` wire struct gains 4 optional fields
         (`gc_ratio` / `gc_max_size` / `gc_stream_debt` / `gc_empty_only`).
         Backward-incompatible at rkyv level; same-commit upgrade for
         manager + PS + client (cluster.sh stops all roles before
         restart). Struct doc says so explicitly.
       - SDK adds `ClusterClient::gc_with_params(part_id, GcAutoParams)`;
         legacy `gc(part_id)` wraps with `Default::default()`.
       - `client gc` CLI gains `--ratio R / --max-size B / --stream-debt B
         / --empty-only` flags; `parse_byte_size` accepts K/M/G/T(i)B
         suffixes. 3 unit tests cover parsing.
