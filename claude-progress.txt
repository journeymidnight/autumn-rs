=== WHAT THIS COMMIT SHIPS ===

  - `crates/rpc/src/manager_rpc.rs`:
    - MSG ids 0x46–0x49 (ACQUIRE / RELEASE / HEARTBEAT_LEASE /
      POLL_INVALIDATIONS).
    - Wire-stable u8 enum constants `LEASE_CLIENT_KIND_*`,
      `LEASE_MODE_*`, `LEASE_INVAL_*` (append-only).
    - rkyv types: `MgrClientId`, `MgrInodeLeaseInfo`,
      `MgrInodeLeaseRecord`, `MgrInvalidation` + 4 Req/Resp pairs.

  - `crates/manager/src/inode_lease.rs` (NEW): `LeaseRegistry`
    state machine + 13 unit tests. `tick(now)` revoke pass captures
    the reader set BEFORE evicting expired readers so a reader that
    expires on the same boundary as the writer's TTL still gets
    the invalidation push (its inbox lives independently of its
    lease entry). Also defines the per-second background loop
    `AutumnManager::inode_lease_revoke_loop` (F228-compliant —
    bounded awaits + spawn_supervised).

  - `crates/manager/src/lib.rs`:
    - mod declaration + `INODE_LEASES_PREFIX = "inode_leases/"`.
    - `AutumnManager.inode_leases: SharedRegistry`.
    - `new()` initializes with `DEFAULT_LEASE_TTL_SECS = 30`.
    - `replay_from_etcd` decodes the prefix and rehydrates writer
      leases via `install_persisted_writer` (deadline clamped to
      configured TTL so a long-future `expires_at` from clock skew
      doesn't pin a dead writer).
    - `start_runtime_tasks` spawns the supervised revoke loop.

  - `crates/manager/src/rpc_handlers.rs`: 4 handlers + dispatch
    entries. Writer-acquire persists `inode_leases/<ino>` via
    `EtcdMirror::put_msgs_txn` (F149 fence); writer-release deletes
    via `put_and_delete_txn`; reader leases bypass etcd. NOT_LEADER
    short-circuit on every handler (matches F210-F6 / F209-A
    leader-gate pattern).

  - `crates/manager/tests/f_ioring_lease.rs` (NEW): 3 integration
    tests that hit the handlers via a real RpcClient against an
    in-process AutumnManager (memory-only, no etcd) — write/write
    conflict returns Precondition, writer-close→reader-poll
    close-to-open coherence, heartbeat→release round trip
    surfaces NotFound after release.

  - `feature_list.md`: F-ioring-lease-1 entry in the Completed
    table + full detail section under new `P14` header.

  - `crates/manager/CLAUDE.md`: Programming Note 34 with the 6
    invariants (L1–L6).

  - `README.md`: F-ioring-lease bridge section pointing at the
    plan + manager smoke-test commands.

=== TESTING CAVEAT ===

  Per [[reproduce_before_fixing_mechanism_bugs]] the preferred
  shape is reproduce → root-cause → fix + review. F-ioring-lease-1
  is GREENFIELD (no production bug being reproduced; the plan is
  fresh, the daemons don't share data with each other yet). The
  16 tests (13 unit + 3 integration) are STRUCTURAL guards on the
  state machine + RPC contract, NOT failure repros. The actual
  multi-daemon coherence guarantee surfaces in F-ioring-lease-4's
  e2e test (two daemons sharing one inode); this commit only ships
  the manager-side primitives those tests will exercise.
