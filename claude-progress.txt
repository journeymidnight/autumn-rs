Behaviour notes / forward-looking rule:
  - autumn-client must not regrow `mgr_call(MSG_*)` for admin RPCs.
    Encoded in crates/server/CLAUDE.md ("Architectural rule" para)
    and in the F213 feature_list entry as a greppable invariant.
  - If future autumn-client needs op data, route through autumn-op
    (separate proposal — do NOT add direct manager calls or extract
    a shared lib without explicit discussion).
  - autumn-client's `op` stub does NOT subprocess-fork autumn-op.
    Print-and-exit is sufficient and matches HDFS dfs+dfsadmin
    convention.
  - autumn-op's new commands all accept --json; bootstrap / format /
    register-node previously had only println output, now offer
    structured JSON for Python automation.
  - cluster.sh runs autumn-op WITHOUT --transport (manager link is
    pure TCP; data-plane transport flag was autumn-client-only).
