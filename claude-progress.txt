Current summary:
  DONE + verified end-to-end on a live 1-node TCP cluster.

  Both recv loops now recv large values straight into a PooledBuf on TCP via a
  compio OWNED read (no FrameDecoder accumulation copy; only the unavoidable
  kernel→userspace copy remains). TCP can't be true zero-copy, so the goal is
  "single-copy". Send side was already vectored/zero-copy on both transports.

  1. New primitive `ReadHalf::read_exact_into_pooled(pb, filled, target)`
     (crates/transport/src/lib.rs): fills pb[filled..target] via
     `pb.slice(filled..target)` + compio `read_exact`, returns the buffer.
     Cancel-safe (compio retains the owned buffer until the read CQE lands).
     UCX errors (callers gate on !is_ucx and use recv_into there).

  2. READ (PS←EN VP value): rpc read_loop IntoPooled gains a TCP branch
     (value ≥ TCP_RECV_INTO_POOLED_MIN_BYTES = 64 KiB) that drains the buffered
     prefix then read_exact_into_pooled the rest. `StreamClient::read_value_into_pooled`
     UCX-only gate relaxed → TCP regular `get` of a VP value now routes through
     MSG_READ_BYTES_ZC (EN side already pooled + value-separable → also delivers
     F216-F's EN-send win for free; F216-F subsumed).

  3. WRITE (PS←client large MSG_PUT_ZC): drain_zc_writes `!is_ucx` early-return
     removed; TCP branch recvs the value via read_exact_into_pooled. perf-check +
     `put-zc` CLI send MSG_PUT_ZC on TCP only for values ≥ 64 KiB (small writes
     stay regular MSG_PUT — 4 KiB hot path is QPS-critical, no copy win there).

  4. CRC removed from the PS hot path, NO toggle: encode_zc_meta writes 0 in the
     crc field (kills EN read-resp + PS get-resp crc passes); read_crc_ok +
     VERIFY_READ_CRC + set_verify_read_crc deleted (kills PS←EN + client←PS
     verify); drain_zc_writes consumes the V1 trailer for stream alignment but no
     longer validates it. 9-byte zc_meta layout unchanged (field reserved/0 →
     wire-compatible). Normal non-ZC frames keep their V1 frame-CRC (F165).
     Value integrity now left to the transport (UCX NIC ICRC / TCP kernel cksum).
