Wave 3 design pattern:
  Each `static CELL: OnceLock<T>` previously hidden inside an env-
  reading helper function is now lifted to module scope:
    static MAX_WRITE_BATCH_CELL: OnceLock<usize> = OnceLock::new();
  Paired with:
    pub fn set_max_write_batch(n: usize) -> bool {
        MAX_WRITE_BATCH_CELL.set(n.clamp(...)).is_ok()
    }
  Reader stays the same shape, with the env::var() call replaced by
  the constant default:
    fn max_write_batch() -> usize {
        *MAX_WRITE_BATCH_CELL.get_or_init(|| DEFAULT_MAX_WRITE_BATCH)
    }
  Binary main() calls every set_* before constructing PartitionServer
  via apply_ps_tunables(&args). First-call-wins guarantees the binary
  value lands.
