=== TESTING CAVEAT ===

  Per [[reproduce_before_fixing_mechanism_bugs]] the preferred
  shape is reproduce → root-cause → fix + review. F-ioring-lease-4
  is greenfield wiring of an already-shipped protocol; the 3 F-4
  integration tests + 4 pure-fn units exercise the invalidation
  bookkeeping end-to-end through the wire. The full byte-level
  "two daemons share an OpenedExtents and the reader sees new
  bytes after the writer's close" repro lives in a deferred full-
  cluster test — same shape as system_ioring_fuse.rs::
  f248_ioring_reads_fuse_file but with two distinct ClusterClient
  sessions.

  The protocol contract end-to-end is now: writer-close →
  ReleaseLease via the writer's ClusterClient → manager bumps
  version + queues WriterClosed → fires the reader's parked
  waker → reader's MSG_POLL_INVALIDATIONS returns within ~ms →
  daemon's session_invalidation_poll_loop runs
  apply_invalidation(events, &mut inv) → per-ino floor bumped
  → next Read against the matching ring_fd hits
  cache_is_stale → reload_extents fetches the post-close
  state. Each step has at least one test covering it.
